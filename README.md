# LeetCode Patterns
 
My LeetCode solutions organized by patterns and reasoning, with each entry focusing on data structure, algorithm and complexity.
Instead of listing problems by number, related problems are grouped into one topic folder so the shared idea is easy to see and compare.
 
## How each entry is written
Every problem follows the same template:
1. **LeetCode number and Title**
2. **Data structure and algorithm**
3. **Concept and complexity** (time and space, plus alternatives and tradeoffs)
4. **Solution**
